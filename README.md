# Personal Site

A personal site — not a résumé, not for client work. Notes, things made by hand,
books, and games, kept in one place.

Built with Astro, styled with the Nord color palette, with light/dark and
English/Chinese switching. Content is organized into five types: **Notes**,
**Makes**, **Books**, **Games**, and an **About** page. New entries are added
through the site's own admin panel at `/admin/` — no code required.

Additional features: full-text search, tags, comments (Google sign-in),
background music, a photo wall, a yearly review page, and social share
previews for Discord and LINE.

Deployed on GitHub Pages as a static site; pushes to `main` trigger an
automatic rebuild and deploy.
